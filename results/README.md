# Article Results

This directory documents the outputs used in the article. The output files are
generated only when an analysis is explicitly run and are ignored by Git.

- `trend_analysis/`: Mann--Kendall results;
- `clustering/`: K-Means and elbow-method results;
- `period_comparison/`: P1, P2, and P3 summaries and percentage differences;
- `health_correlations/`: seasonal Spearman correlations;
- `hazard_maps/`: heatwave hazard maps;
- `vulnerability_maps/`: older-population and traditional-community maps;
- `risk_maps/`: compound hazard-vulnerability maps.
